# PySpark Learning Journey 🚀

A structured, hands-on learning repo covering PySpark from core concepts to production pipelines.

## Curriculum

| # | Module | Topics |
|---|--------|--------|
| 1 | **Core Concepts** | RDDs vs DataFrames, DAG, lazy evaluation, Spark architecture |
| 2 | **Transformations & Queries** | Narrow/wide transforms, joins, window functions, UDFs |
| 3 | **Performance Tuning** | Partitioning, caching, shuffle, skew handling, AQE |
| 4 | **MLlib** | Pipelines, feature engineering, cross-validation, model persistence |
| 5 | **End-to-End Pipelines** | Medallion architecture, streaming, production patterns |

## Branch Structure

- `main` — curriculum overview and reference material
- `solutions` — exercise solutions (one file per topic, never merged to main)
